🌍 Global Education Data Analysis

📌 Objective

This project analyzes the relationship between:
	•	Government Education Expenditure
	•	Primary School Enrollment
	•	Adult Literacy Rate
	•	Gender Gap in Literacy

Using World Bank education data.

⸻

📊 Key Findings
	•	📈 Primary Enrollment strongly improves Adult Literacy (r ≈ 0.83)
	•	📉 Primary Enrollment significantly reduces Gender Gap (r ≈ -0.66)
	•	💰 Government Spending shows weak direct impact
	•	🌍 Regional disparities persist (South Asia & Sub-Saharan Africa show higher inequality)

⸻

🔍 Structural Insight

Access to education (enrollment) is the key mechanism through which education systems improve literacy and reduce gender inequality. Spending alone is not sufficient unless it effectively increases enrollment.
